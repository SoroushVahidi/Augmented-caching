# Cross-Environment Evidence Matrix

**Purpose:** the single authoritative place that resolves "this experiment
looks unfinished in one environment but may exist elsewhere." An experiment
can simultaneously be `PENDING` on the local workstation, `COMPLETE` on
Wulver, and absent from GitHub -- this file is where those three views get
reconciled into one row instead of contradicting each other across docs.

**Provenance of the Wulver-side facts below:** this workstation historically
did not contact Wulver directly (see repository-wide safety constraints).
Most Wulver-side rows in this matrix were relayed by the user from a
separately audited Wulver-side session and recorded here verbatim, with job
IDs and hashes as given, and are labeled `WULVER_ONLY_VALIDATED` rather than
independently verified by this workstation. **Exception (2026-08-13):** under
an explicit task authorization, this workstation directly `rsync`'d two
FINAL_VALIDATED payloads from the authoritative Wulver checkout
(`login02:/mmfs1/project/ikoutis/sv96/Augmented-caching`) -- the corrected
held-out `evict_value_v1` treatment and the controlled timing campaign -- and
independently verified their SHA-256 hashes and re-ran structural/statistical
audits locally on the transferred raw files. Those two rows are now labeled
`FINAL_VALIDATED_SYNCED`, not `WULVER_ONLY_VALIDATED`. All other rows below
remain relayed-only; re-verify job status/hashes directly before citing them
in a manuscript.

**Last reconciled:** 2026-08-13 (corrected held-out `evict_value_v1` treatment

## Columns

- **Local workstation**: does the artifact/result exist on this machine's disk (any worktree), and is it git-tracked or gitignored-generated?
- **Wulver**: what's known about remote cluster state, per the provenance note above.
- **GitHub/source**: is the *code* (not the result) pushed to `origin`?
- **Authoritative artifact**: the one path/hash that should be cited, whichever environment it lives in.
- **Status**: canonical vocabulary (`FINAL_VALIDATED`, `COMPLETE_DIAGNOSTIC`, `COMPLETE_PARTIAL_SCOPE`, `EXPERIMENTALLY_COMPLETE_SYNTHESIS_PENDING`, `RUNNING`, `PENDING`, `WULVER_PENDING`, `LOCAL_RUNNING_FALLBACK`, `LOCAL_COMPLETE`, `LOCAL_EXACT_PROTOCOL_VALIDATED`, `LOCAL_EXACT_PROTOCOL_VALIDATED_WITH_CAVEAT`, `LOCAL_EXACT_PROTOCOL_VALIDATED_WITH_PROVENANCE_CAVEAT`, `IMPLEMENTATION_READY`, `IMPLEMENTATION_REPAIRED_SMOKE_VALIDATED`, `PRODUCTION_RUNNER_READY_SMOKE_VALIDATED`, `NOT_PRODUCTION_LAUNCH_READY`, `SMOKE_ONLY`, `BLOCKED`, `WULVER_ONLY_VALIDATED`, `CONCEPTUAL_BUT_NOT_PRODUCTION_READY`).
- **Promotion needed**: what has to happen for the authoritative artifact to become locally reproducible / on GitHub.
