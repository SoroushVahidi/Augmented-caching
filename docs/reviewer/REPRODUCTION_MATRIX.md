Cost guide:

- Cheap: unit tests, schema checks, Markdown link checks, summary-table
  inspection.
- Moderate local: small policy tests and some single-policy replays if traces
  and optional dependencies are present.
- Expensive full campaigns: corrected held-out treatment, objective ablation,
  continuation, distribution-shift, and controlled timing.
- Wulver/HPC: large regenerated campaigns or synced raw result production.
