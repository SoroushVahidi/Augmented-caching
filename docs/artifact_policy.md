# Artifact policy

This document defines the categories of generated and tracked files in the `Augmented-caching` repository.

## Artifact categories

| Category | Typical location | Tracked in Git? | Policy |
|----------|------------------|-----------------|--------|
| **Source code** | `src/`, `scripts/` | **Yes** | Primary research implementation. |
| **Configs** | `configs/` | **Yes** | Authoritative protocol and parameter definitions. |
| **Documentation** | `docs/`, `README.md` | **Yes** | Methodology, reproduction, and audit guides. |
| **Trace manifests** | `analysis/manifests/` | **Yes** | Definition of dataset splits and experiment ranges. |
| **Canonical results** | `analysis/manuscript_canonical/` | **Yes** | Frozen evaluation tables used in the manuscript. |
| **Reviewer results** | `analysis/reviewer_revision/` | **Yes** | Frozen results from revision experiments. |
| **Figures/Tables** | `figures/`, `tables/` | **Yes** | Manuscript-ready assets generated by builders. |
| **Raw data** | `data/raw/` | **No** | Huge original trace files. |
| **Processed data** | `data/processed/` | **No** | Intermediate trace formats (except small examples). |
| **Derived data** | `data/derived/` | **No** | Large feature tables and supervised targets. |
| **Trained models** | `models/` | **Partial** | Only small frozen models essential for reproducibility. |
| **Exploratory analysis**| `analysis/exploratory/` | **No** | First-checks and ad-hoc ablations. |
| **Diagnostics/Logs** | `analysis/diagnostics/`, `logs/` | **No** | Audit logs and performance benchmarks. |
| **Submission packs** | `artifacts/` | **No** | Final ZIP/DOCX packages for journals. |

## Version control guidelines

1. **Do not commit** large binary files (models > 10MB, large traces, ZIP packs).
2. **Do not commit** absolute paths or environment-specific files.
3. **Commit** all provenance metadata (`manifest.json`, `provenance.json`) associated with scientific artifacts.
4. **Commit** only the final, frozen version of experiment results intended for the manuscript.

## Retention and cleanup

- **Canonical** artifacts are kept indefinitely for reproducibility.
- **Exploratory** artifacts in `analysis/exploratory/` are periodically cleared or moved to `archival/` subdirectories.
- **Active** experiment staging areas in `models/` or `data/derived/` are maintained until the corresponding job completes.
