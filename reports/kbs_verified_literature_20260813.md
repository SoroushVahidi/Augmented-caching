## Rejected / not used

- **SCION: Size-aware Policy Orchestration for Nonstationary Object Caches.** No authoritative peer-reviewed proceedings record was verified in this audit, and the available preprint-level material did not add a necessary distinction beyond the verified 2025--2026 cache-efficiency work. It is not cited.
- **Unverified numerical claims for LAH, Merlin, GL-Cache, HALP, and 3L-Cache.** Only qualitative claims are used in the revised manuscript unless the number was visible on the authoritative proceedings page and was needed for the argument.
- **A claim that the present target is the first candidate-level learned cache objective.** Rejected as overbroad because HALP, PARROT, LRB, 3L-Cache, and related systems already establish nearby candidate-level or future-derived learning designs.
- **A claim that all modern cache systems move ML off the hot path.** Rejected as overbroad; the manuscript now says only that several recent systems reduce learned hot-path cost through different mechanisms.

## Workload provenance verified against repository preprocessing

The evaluated artifact is the seven 50,000-request traces listed in `analysis/kbs_r2_major1_evidence_prep_20260811/trace_manifest.json` and `analysis/wulver_trace_manifest_full.csv`. The transformation rules are code-backed:

| Family | Source status | Repository transformation |
|---|---|---|
| BrightKite | SNAP check-ins/location events | `venue_id` becomes `item_id`; timestamps are retained; first 50,000 parsed records are used. |
| Citi Bike | Official trip histories | `start_station_id` becomes `item_id`; trip order is retained; first 50,000 parsed records are used. |
| CloudPhysics | Production block-I/O trace collection via cacheMon | Read-like records are retained; LBN is mapped to a logical page using the configured 4096-byte page size; first 50,000 records are used. |
| MetaCDN | Meta CDN cache-derived trace via cacheMon/CacheLib | Manifest-selected object identifiers are replayed; first 50,000 records are used. |
| MetaKV | Meta key-value cache-derived trace via cacheMon/CacheLib | Manifest-selected keys are replayed; first 50,000 records are used. |
| Twemcache | Twitter anonymized production cache trace | Manifest-selected cluster/sample records are parsed; anonymized keys become request items; first 50,000 records are used. |
| Wikimedia | Pageview-derived public request source | Pageview object IDs become request items; first 50,000 records are used. |

The first two families are therefore locality-stress event streams rather than production cache traces. The four cache/storage families are production-derived or cache-derived according to the source documentation. Wikimedia is explicitly a pageview-derived proxy in this study; it is not silently treated as the Wikimedia CDN trace listed separately in the cacheMon collection.

The revised related-work and practical-impact text uses qualitative descriptions only.
